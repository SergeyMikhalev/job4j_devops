###  Проект job4j_devops - Изучение CI\CD

### Краткое описание
Данный проект предазначен для изучения практик CI\CD.
CI/CD (Continuous Integration, Continuous Delivery — непрерывная интеграция и доставка) 
— это технология автоматизации тестирования и доставки новых модулей разрабатываемого 
проекта заинтересованным сторонам (разработчикам, аналитикам, инженерам качества, 
конечным пользователям и др.). 

### Стэк технологий
- Core: Java 17, Gradle 8.11.

### Окружение
Для запуска проекта понадобятся
- Java 17
- Gradle 8.11
